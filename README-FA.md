# بازی «اسم‌فامیل اشیاء» 🎲

بازی کلمات فارسی برای کودکان، نوجوانان و خانواده‌ها — کامل، فارسی، راست‌چین و موبایل‌فرست.

سه حالت بازی:
| حالت | توضیح | اینترنت |
|---|---|---|
| 🤖 رقیب مجازی | ۱ تا ۹ ربات با سطح آسان/متوسط/سخت | لازم ندارد |
| 🎉 دورهمی آفلاین | ۲ تا ۱۰ نفر با یک گوشی (نوبت‌دهی خصوصی) | لازم ندارد |
| 🌐 آنلاین | اتاق با کد دعوت تا ۱۰ بازیکن | لازم دارد |

**امکانات:** ۱۲ دسته پیش‌فرض + دسته شخصی، بانک ~۱۵۰۰ واژه قابل توسعه، امتیازدهی استاندارد (یکتا ۱۰ / تکراری ۵)، نرمال‌سازی فارسی (ی/ك/نیم‌فاصله)، اعتبارسنجی واژه + بررسی ناشناخته‌ها، نشان‌های افتخار، آواتار و تم، افکت صوتی، حالت روشن/تاریک، بازاتصال خودکار در بازی آنلاین، امتیازدهی سروری ضدتقلب.

---

## ۱. اجرای سریع (روی ویندوز یا هر سیستم‌عامل)

پیش‌نیازها: [Node.js 20+](https://nodejs.org) و [Bun](https://bun.sh) (یا فقط Node.js + npm).

```bash
# ۱) نصب وابستگی‌های برنامه اصلی
bun install          # یا: npm install

# ۲) اجرای برنامه (پورت 3000)
bun run dev          # یا: npm run dev
# → مرورگر: http://localhost:3000
```

## ۲. اجرای سرور آنلاین (برای حالت آنلاین)

```bash
cd mini-services/game-server
bun install          # فقط بار اول
bun run dev          # سرور روی پورت 3003 بالا می‌آید
```

بازی آنلاین نیاز دارد برنامه اصلی (3000) و سرور (3003) همزمان روشن باشند.
در محیط عملیاتی، درخواست‌های بازی آنلاین باید از طریق یک reverse proxy (مانند Caddy یا Nginx) به پورت 3003 هدایت شوند — نمونه پیکربندی در `Caddyfile` پروژه موجود است (کلاینت به `/?XTransformPort=3003` وصل می‌شود).

## ۳. ساختار پروژه

```
src/
  app/                 صفحه اصلی (Next.js 16 App Router)
  components/game/     همه صفحات بازی (۱۲ صفحه)
  lib/game/            منطق خالص بازی: نرمال‌سازی، امتیازدهی، حروف، ربات، بانک
  lib/sound.ts         افکت‌های صوتی (Web Audio — بدون فایل)
  store/               وضعیت‌ها (Zustand): پروفایل، تنظیمات، بازی، آنلاین
  data/wordbank/       بانک واژگان فارسی (JSON — قابل توسعه)
mini-services/game-server/   سرور آنلاین Socket.IO (مستقل)
scripts/wordbank.ts    ابزار مدیریت واژگان (CLI)
docs/                  همه راهنماها
```

- ذخیره‌سازی آفلاین: `localStorage` (پروفایل، تنظیمات، دسته‌های شخصی، سوابق)
- سرور آنلاین: حافظه + ذخیره نتایج در `mini-services/game-server/data/results.json`

## ۴. بازیکن چی‌کار می‌تواند بکند؟

- بدون ثبت‌نام بازی کند (نام مستعار + آواتار کارتونی)
- دسته بسازد/ویرایش کند و مجموعه دسته‌های محبوبش را ذخیره کند
- سطح حروف (آسان/معمولی/سخت)، زمان دور، تعداد دور و ربات‌ها را تنظیم کند
- پاسخ ناشناخته‌ها را (به‌عنوان میزبان) قبول یا رد کند
- رکورد، سوابق و نشان‌های افتخار ببیند
